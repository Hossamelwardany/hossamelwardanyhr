# HOSSAM ELWARDANY — Premium Personal Brand Website

نسخة Landing / Executive Consulting Website جاهزة للرفع على GitHub ثم Vercel.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — الهوية والتصميم Responsive
- `script.js` — القائمة، الأنيميشن، العودة للأعلى
- `assets/profile.webp` — ضع صورتك الشخصية هنا

## أهم ما تم تطويره
- Hero أقوى مع Executive positioning
- هوية Navy / Gold / White
- Responsive للموبايل والتابلت والكمبيوتر
- SEO + Open Graph basics
- Accessibility labels
- Services / Method / Case Studies / Insights / CTA
- Micro-interactions وحركة دخول خفيفة
- زر WhatsApp جاهز
- تحذير قانوني في الـFooter
- لا توجد مكتبات JS خارجية

## إضافة صورتك
ضع صورتك باسم:
`assets/profile.webp`

ويُفضّل WebP أو JPG بجودة جيدة، صورة رأسية احترافية.

## تعديل روابط السوشيال
افتح `index.html` وابحث عن:
`href="#"`

واستبدلها بروابط LinkedIn / Facebook / Instagram الفعلية.

## النشر على GitHub + Vercel
1. أنشئ Repository جديد في GitHub.
2. ارفع الملفات كما هي.
3. في Vercel اختر Add New → Project → Import Git Repository.
4. اترك الإعدادات الافتراضية للموقع الثابت ثم Deploy.

بعد ربط GitHub، كل Push للفرع الرئيسي يمكن أن يؤدي إلى Deployment جديد تلقائيًا في Vercel.

## ملاحظة
النصوص والأرقام الحالية مبنية على المعلومات الظاهرة في النسخة الحالية للموقع. قبل الإطلاق النهائي، راجع بيانات التواصل، الروابط، أرقام المشروعات، الشهادات، وصور الأعمال الفعلية.
